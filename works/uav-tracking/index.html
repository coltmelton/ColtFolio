01 / Aerial Perception

UAV Object Detection & Tracking

An experimental video pipeline that detects objects in aerial footage, keeps identities consistent across frames, and estimates local positions for tracked motion.

Focus
Real-time video perception
Core tools
Python · YOLOv8 · OpenCV · WebSockets
Status
Experimental; coordinate mapping requires further evaluation

System overview

From frames to tracks.

Video from a webcam, IP stream, or DJI-oriented source is sent to a Python inference service over WebSockets. The service detects objects, associates detections over time, and returns annotated tracking results with approximate local coordinates.

  • Video transportStreamed frames with resolution, quality, and rate available for tuning.
  • Per-frame inferenceYOLOv8 detections provide object classes and image-space boxes.
  • Identity over timeMulti-object tracking associates detections between frames.
  • Honest limitationsCoordinate mapping is experimental and is not presented as validated georeferencing.

Pipeline

Video source → WebSocket transport → object detector → multi-object tracker → approximate coordinate mapper → annotated output.
