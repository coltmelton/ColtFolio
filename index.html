Research

Machine Learning-Guided Raman Spectral Decomposition

Senior thesis research in noisy-sensor interpretation: decomposing complex Raman spectra into baseline and overlapping peak components so measurement pipelines can produce explainable, validated signals for high-consequence engineering decisions.

2.9M parameters baseline + up to 3 peaks 512-point windows 602 spectra 19,753 pure-peak matches 0.9999 mean R2 Calibration R2 up to 0.982

Problem

Fielded sensing systems rarely produce clean signals. Raman spectra contain baselines, overlapping peaks, and concentration-dependent behavior that make direct peak isolation difficult to trust in calibration, diagnostics, and automated analysis.

Approach

Built a machine-learning-guided decomposition pipeline that predicts baseline and peak components across 512-point windows, then validates extracted features against reference matching logic before they are used downstream.

Architecture

Implemented a 2.9M-parameter PyTorch 1D U-Net with physics-aware fitting, peak matching, residual analysis, and calibration evaluation so each prediction had an audit trail.

Results

Evaluated 602 spectra, produced 19,753 pure-peak matches, achieved 0.9999 mean R2 reconstruction accuracy, and reached calibration R2 up to 0.982 while preserving interpretable intermediate outputs.

Tech Stack

Python, PyTorch, NumPy, pandas, 1D signal processing, spectroscopy data pipelines, calibration modeling, peak matching, residual diagnostics, and validation tooling.

What I Learned

Useful ML for sensing systems is not just a model score. It needs validation hooks, interpretable failure modes, calibration context, and tooling that lets engineers challenge the result before acting on it.
